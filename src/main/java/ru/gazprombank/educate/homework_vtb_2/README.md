Условие:
Вам в работу поступило ТЗ с описанием входящего json и описанием n полей.
Одно из из этих полей - inn.

В описании аналитик указал след. информацию
Ключ: inn
Описание: Идентификационный номер налогоплательщика (ИНН)
Обязательность: +
Пример: 1234567890

Во время проверки ТЗ и разработки к Вам приходит разработчик и сообщает, что его руководителю не понравилась реализация,
а именно

@NotNull
Integer inn;

Разработчик просит Вас ему помочь "придумать" нормальную валидацию для данного поля.
Аналитик улетел в тур поход в Антарктиду и не доступен для связи.

Задание: придумать какой должна быть корректная валидация для inn и описать тестовые примеры, которые использовались бы для тестирования.
Ссылка на изучение примеров валидаторов: https://www.baeldung.com/java-validation
Примечание\подсказка: Игнорировать алгоритмы заполнения после 2 символа.
